## 新旧两套体系怎么对上

对不上的地方主要有三处：名字、切换规则、Heavy 与 Ultra 的价格倒挂。

名字不能互换。SuperGrok Lite / 标准版 / Plus / Heavy 是旧体系的产品名，Free / Plus / Premium / Super / Ultra 是新体系的档位名。美国 Apple 商店列表至今仍挂着 SuperGrok Lite、SuperGrok、SuperGrok Plus、SuperGrok Heavy 四个旧产品名，同一个"SuperGrok"在 App Store 里可能同时对应 $30 月付和 $300 年付两个金额，因为列表没有给每个产品标清计费周期。

切换是可选的，也不是无损的。现有 SuperGrok、Cursor、X Premium 订户可以留在原套餐，也可以去账单设置里切换。切换会取消符合条件的旧计划，未使用时间按比例退款，退款单独退回原支付方式，然后新套餐立刻按全价开始新的计费周期。也就是说切换当月你会同时看到一笔退款和一笔全额扣款，不是抵扣后的差价。

价格倒挂这件事值得单独说：旧体系最高档 SuperGrok Heavy 是 $300/月，新体系的最高档 Ultra 是 $200/月，便宜 $100。Heavy 的定位是最高用量加高级多智能体能力，Ultra 的定位是 50× Plus 用量并包含 Super 的全部功能。如果你正在为 Heavy 付 $300，并且不需要保留旧账单结构，转成 Ultra 每月能省下 $100，前提是你确认自己用不到 Heavy 那套专属能力。

## 每一档到底给什么

$30 这一档的能力边界最值得记清楚，因为大部分人会落在这一档。

标准 SuperGrok 和 X Subscription Premium 在 Grok 侧给的东西基本一致：Grok 4.6、Grok Bot、Connectors、更高的速率限制、Expert 能力、图像生成、视频生成，Web、iOS、Android 三端同步。Premium 额外把 Cursor Pro 和 X Premium+ 打包进来。

Grok Bot 不是聊天框里的一个模式。每个 Bot 背后是一台持久的云端 Linux 虚拟机，有自己的浏览器、文件系统和终端，能打开网页、点击按钮、填表单、截屏，笔记本合上它还在跑。你可以同时开几个 Bot，让它们互相发消息、在群聊里交接任务，也可以带它走一遍流程，存成 skill 之后定时重跑。这是 $30 档相对 $10 档最实质的差别。

视频分辨率按档位分。官方 Grok 页面描述的视频生成是 720p、最长 15 秒，SuperGrok Plus 明确宣传支持 1080p，新的 Super 档写的是 1080p 15 秒视频。只在 Lite 或 $8 Plus 上做视频，别指望画质。

模型版本要看清楚。Grok 4.7 于 2026 年 9 月 21 日面向 Cursor 和 Grok Build 发布，另有独立 API 可用性，这不等于 Grok 聊天端已经全面换成 4.7。当前聊天端的主力仍是 4.6，价格页的措辞是"最新 Grok 模型"，具体版本以你登录后看到的为准。

Companions 只在 iOS 上可用，订阅本身跨平台同步，但这个功能不跟着走。

## 额度怎么算，超了怎么办

付费档不是无限用量。2026 年 6 月起，付费用户的额度改成共享的、按算力加权的每周额度池，取代了此前按产品分开的每日限额。

按算力加权意味着不同操作消耗不一样，一次长上下文推理和一次短问答不是同一个价。Settings → Usage 里能看到当前周期已消耗的百分比、分产品明细和重置日期，这是唯一准确的查看位置，别靠数消息条数估算。

到顶之后付费功能暂停到下次重置，免费 Chat 和 Voice 的额度仍然可用。要继续干活有两条路：网页端买 Extra Usage Credits，起价 $5，除另有说明一般购买后一年过期；或者等周额度重置。

API 是另一套账。付费计划包含 API 访问，但 API 调用按模型费率单独计费，不占用订阅的用量池。Cursor 里的第三方模型（Claude、GPT 那些）在每一档都按 API 标价单独计费，从第一次使用就开始扣，这部分不在月费里。

## 退款、取消与试用

取消要在下次扣费前至少 24 小时操作，否则会正常续上一个月。

网页端在 Settings → Billing 里取消。Apple 端走 设置 → 姓名 → 订阅 → Grok 订阅 → 取消，订阅页没有取消按钮或者出现红色到期提示，说明已经取消了。Android 走 Google Play 管理，卸载 App 不会取消订阅。

退款要看购买渠道。网页端和 Google Play 的 SuperGrok 退款走 xAI 官方退款申请，获批后一般 5–10 个工作日退回原支付方式；App Store 的退款由 Apple 处理。取消本身不会自动退已付款项，这两件事是分开的。

区域冷静期不一样长：欧洲条款给 14 天窗口，捆绑条款下可能扣除已使用部分；巴西、墨西哥、韩国 7 天；台湾 5 天。中国大陆不在这些条款覆盖范围内。

官方还有一条 14 天免费 Premium 试用，但它是推荐计划，不是公开优惠：需要绑卡，除非取消否则按结账价加税自动续费；要求被推荐人此前没有 Grok/X Subscription 试用记录，且过去 12 个月内没有 Grok、SuperGrok、X Premium 或 Cursor 的付费计划；移动商店购买不适用；被推荐人须在中国以外。换句话说，对绝大多数中文读者，这条用不上。

第二，代充的本质是交出账号密码或验证码。xAI 的安全口径写得很直接：不要向任何第三方提交密码、验证码、Cookie、Token、API Key 或完整 session 内容。交出去之后，账号被风控、订阅被收回、申诉无门，这些在社区里不是孤例。

## 常见问题

**$30 到底是 SuperGrok 还是 X Subscription Premium？**

看你从哪里进。新买家从官网价格页走，看到的是 X Subscription 的 $30 Premium 档；从应用内旧升级页走，可能落到 SuperGrok 标准档。两者同价，Premium 多含 Cursor Pro 与 X Premium+，所以新买家没有理由选独立 SuperGrok。

**只想用 Grok Bot，要不要买 Heavy？**

不需要。$30 档起就含 Grok Bot，Heavy 贵在用量上限和高级多智能体能力。如果 Bot 是唯一理由，Cursor Pro（$20/月）也包含 Grok Bot，可以先算一下哪个更贴合你的工作流。

**年付能省多少？**

每一档都省约 17%，相当于两个月免费。旧体系 SuperGrok 年付 $300、Plus $1,000、Heavy $3,000；新体系 Premium $300、Super $1,000、Ultra $2,000。年付的代价是一次性付清，且切换套餐时退的是未使用时间，不是全额。

**API 包含在订阅里吗？**

不包含。订阅给的是产品内的用量池，API 按模型费率单独计费，两者账单独立。Cursor 里的第三方模型同样单独计费。

**取消后还能用到什么时候？**

用到当前计费周期结束。提前 24 小时以上取消，就不会产生下一期扣费；周期内剩余时间不退，除非你走退款申请或落在区域冷静期条款内。

**能和家人共享吗？**

官方产品文档没有确认 SuperGrok 支持 Apple 家庭共享，订阅页没有"与家人共享"开关就表示不支持。Grok 消费者条款禁止共享账号凭证或让账号供他人使用，包括家人。
